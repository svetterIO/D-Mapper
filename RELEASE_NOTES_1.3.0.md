# D-MAPPER v1.3.0

First GitHub Pages-ready release under the **D-MAPPER** name.

## Highlights

- New product identity: **D-MAPPER — Bidirectional Data Mapping**.
- Static `index.html` suitable for GitHub Pages with no build step.
- Existing X-Mapper browser state is migrated where the same origin makes it available.
- Rule exports now use `d-mapper-*` filenames.
- Corrected match-count reporting.
- Released under the MIT License.

## Release assets

Attach `d-mapper-1.3.0.html` to the GitHub Release if you want users to download a version-pinned standalone file. The Pages site itself should continue to use the repository's unversioned `index.html`.
- Added an animated README demo illustrating forward/reverse mapping and the global rules toggle.
